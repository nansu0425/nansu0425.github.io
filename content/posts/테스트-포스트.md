## 문제

`claude/mobile-blog-setup-Qcusj` 브랜치에서 구축한 모바일 작성 환경이 실제 빌드 파이프라인과 충돌 없이 동작하는지 확인해야 한다.

## 배경

- 새 포스트는 `draft: true`로 시작 → `hugo --gc --minify` 빌드에서 제외
- `main` 브랜치에 푸시해도 사이트에 노출되지 않음
- GitHub Actions가 정상적으로 빌드를 트리거하는지, draft 포스트가 사이트에 노출되지 않는지 검증

## 확인 항목

- `content/posts/테스트-포스트.md`가 올바른 한국어 kebab-case 경로로 생성되었는가
- frontmatter가 YAML 규약을 따르는가 (`title`, `date`, `tags`, `categories`, `summary`, `description`, `draft`)
- `math: false`, `tikz: false`로 두어 불필요한 CDN이 로드되지 않는가
- `main` 푸시 후 GitHub Actions 빌드가 성공하는가
- 사이트(`https://nansu0425.github.io`)에 이 포스트가 **노출되지 않는가** (draft 동작 검증)

## 요약

- 이 포스트는 모바일 Claude Code 환경 구축의 end-to-end 검증용
- 검증이 끝나면 파일을 삭제하거나, 필요하다면 실제 콘텐츠로 덮어쓴 뒤 `draft: false`로 공개
